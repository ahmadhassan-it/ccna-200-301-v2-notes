# CCNA 200-301 v2.0 Study Notes

My topic-by-topic study of the Cisco CCNA 200-301 **v2.0** exam topic list, in list order (1.1, 1.2, 1.3 ...).

Each topic folder has one file, `notes.md`. It is written so I can revise the whole lesson from zero:
the problem, the idea, diagrams, commands, show-output examples, common mistakes, my lab, a self-test, and my mistake log.

## How these notes are made

I study with an AI study coach (Claude, made by Anthropic). The coach explains each topic, tests me, checks my labs, and writes the first draft of the notes.
I do the labs myself in Cisco Packet Tracer, I answer the test questions in my own words, and the mistake logs show my real mistakes.
I read and edit every note before I publish it.

> These notes are **not** exam dumps, and they do not contain real exam questions.
> All practice questions are written by my study coach, and all show outputs are examples.
> The official topic wording is in Cisco's v2.0 exam topic list.

## How I study each topic

1. Test first (own words, no easy options)
2. Learn only what I got wrong, in small chunks
3. Lab from memory in Cisco Packet Tracer
4. Must-memorize list
5. Level check: can I explain it, configure it, troubleshoot it?
6. Write `notes.md`, check it for mistakes, then publish
7. Retest later (spaced review)

## Level legend

- **E** = I can explain it
- **C** = I can configure it
- **T** = I can troubleshoot it
